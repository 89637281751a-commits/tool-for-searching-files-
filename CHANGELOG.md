# История обновлений

## 0.1.0 — 27 ноября 2026

Первый предварительный выпуск QuickFind для Windows 10 и 11. [Скачать установщик и посмотреть выпуск](https://github.com/89637281751a-commits/tool-for-searching-files-/releases/tag/v0.1.0)

- MSI устанавливает готовый QuickFind для текущего пользователя и добавляет ярлык в меню «Пуск».
- Приложение открывает тёмное окно поиска по двойному нажатию Ctrl. Пустой запрос показывает до десяти недавних файлов.
- Автозапуск при входе в Windows включается через меню значка QuickFind. При обновлении сохраняется существующая настройка.
- Проверка на Windows подтвердила замену старой установки, обновление MSI с сохранением индекса, блокировку понижения версии и штатное удаление. [Результаты проверки](https://github.com/89637281751a-commits/tool-for-searching-files-/actions/runs/46062053099)

Установщик без цифровой подписи.
