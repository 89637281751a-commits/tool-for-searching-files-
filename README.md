# QuickFind

Поиск файлов для Windows 10 и 11. Дважды нажмите Ctrl, введите часть имени и нажмите Enter, чтобы открыть выбранный файл в программе по умолчанию. Пустой запрос показывает до десяти недавно открытых файлов.

## Установка

Скачайте проект через **Code → Download ZIP**, распакуйте архив и запустите `Install.cmd`. Для обновления сначала выберите **Выход** в меню значка QuickFind рядом с часами.
