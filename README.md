# QuickFind

Поиск файлов для Windows 10 и 11. Дважды нажмите Ctrl, введите часть имени и нажмите Enter, чтобы открыть выбранный файл. Пустой запрос показывает до десяти недавних файлов.

## Установка

1. На странице [Releases](https://github.com/89637281751a-commits/tool-for-searching-files-/releases) откройте нужный выпуск и скачайте файл `QuickFind-<версия>.msi` по ссылке в его описании.
2. Откройте MSI. После установки запустите **QuickFind** из меню **Пуск**.
3. Чтобы запускать QuickFind при входе в Windows, включите эту настройку через значок программы рядом с часами.

Для обновления сначала выберите **Выход** в меню значка рядом с часами, затем откройте MSI новой версии. История и индекс сохраняются. Для удаления используйте **Параметры → Приложения**. [Подробная инструкция](Readme.txt)

## Сборка MSI

На Linux с .NET SDK 8, Python 3 и wixl 0.103 или новее выполните `bash installer/build.sh`. MSI появится в `bin/installer/<версия>/`. Версия релиза задаётся в `QuickFind.csproj`.
