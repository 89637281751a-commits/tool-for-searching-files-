Быстрый поиск файлов для Windows 10/11

Обновление
В меню значка QuickFind рядом с часами выберите «Выход». Распакуйте весь
новый архив и запустите Install.cmd. При обновлении установщик заменит
программу и сохранит историю, индекс и ваш выбор автозапуска.

Первый запуск
1. Распакуйте архив в обычную папку.
2. Дважды щёлкните Install.cmd. Установщик соберёт программу встроенным
   компилятором .NET Framework 4.x и запустит её для вашей учётной записи.
3. Введите часть имени файла. При первом запуске программа обходит доступные
   папки всех локальных фиксированных дисков. Первые результаты появляются
   по мере обхода. Длительность зависит от количества файлов и скорости дисков.

Использование
Дважды нажмите и отпустите Ctrl, затем набирайте имя. При пустом запросе
вы увидите до 10 недавних файлов. Дубликаты по полному пути объединяются.
История учитывает файлы, открытые через поиск, и записи из папки Windows
«Недавние документы». Если Windows не ведёт историю, файлы из Проводника
не появятся в списке недавних, но останутся доступны через поиск по имени.

Стрелки вверх и вниз выбирают файл. Enter открывает его в программе,
назначенной в Windows. Esc скрывает окно. В списке видны имя и папка.
«ДЗ1» находит «ДЗ1.pdf» и «ДЗ10.pdf». «ДЗ 1.pdf» — другой запрос.
Поиск игнорирует регистр букв и учитывает пробелы. Сначала идут точные
совпадения, затем совпадения в начале и в остальной части имени. Внутри
группы предпочтение получают недавно открытые файлы, известные программе.

При установке включается запуск в фоне при входе в Windows. Его можно
отключить через меню значка программы в области уведомлений. Там же есть
пункты «Открыть поиск» и «Выход».

Индекс охватывает обычные файлы на внутренних дисках, доступные вашей
учётной записи. Программа пропускает каталоги-ссылки и собственную папку.
Она отслеживает переименования, добавления и удаления; раз в 30 минут
повторяет обход, чтобы учесть изменения дисков и пропущенные события.
При большом количестве совпадений показываются первые 100.
Индекс и история хранятся в %LOCALAPPDATA%\QuickFind.

Для удаления отключите автозапуск через меню значка, выберите «Выход»
и удалите папку %LOCALAPPDATA%\QuickFind.
